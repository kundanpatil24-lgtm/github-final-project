# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest (annual percentage)
- Time period

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script prompts the user for the principal, rate of interest, and time period, then displays the calculated simple interest and total amount.
